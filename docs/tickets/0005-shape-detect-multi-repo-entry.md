# 0005: 形态判定三分支与多仓模式入口

**做什么：** 在根目录（非 git 仓库）运行 /setup-workspace 时，技能能识别"根下第一层
存在 git 仓库"并进入多仓工作区模式；第一层没有任何 git 仓库时维持现行拒绝且零写入；
仓库内运行时现行单仓 / monorepo 行为完全不变。

**验收标准：**
- [ ] SKILL §0 呈现三分支（rev-parse 成功 → 现行流程；失败且第一层 ≥1 个 git 仓库 →
  多仓模式；失败且第一层无 git 仓库 → 拒绝、零写入），scan-signals §1 增补第三形态
  与第一层扫描信号（跳过点目录），两处文本一致无矛盾
- [ ] 临时夹具演练：根含 ≥1 个 git 仓库目录 → 走查判定进多仓模式（记录贴 Progress）；
  空根目录 → 输出拒绝话术且以 `find` 证明零写入
- [ ] 回归：在 git 仓库内运行走现行分支，不进多仓逻辑
