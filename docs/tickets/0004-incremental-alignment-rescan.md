# 0004: 增量对齐与补扫协议（重跑语义）

**做什么：** 给 setup-reconstruct 补上重跑语义：增量对齐——读扫描基线 commit，取基线到 HEAD 的变更文件集，按证据引用把存量断言分为涉漂移 / 未涉漂移两组，只重验涉漂移断言（证据失效重取证或确认后标过时），新文件产出增量草案，全部更新走同一确认门后合并写入，不推倒未漂移部分，完成后逐张更新基线；基线缺失回落全量扫描。补扫——带范围参数的重跑，只动基线标注的未覆盖范围。协议落技能参考文档，seam 3 文本契约同步扩展。

- [ ] FR-5（spec 场景 7）：补扫协议成文——范围参数、只产出该范围增量产物、更新基线覆盖清单、已确认存量产物不被重写
- [ ] FR-7（spec 场景 9）：增量对齐协议成文——diff 定位漂移、按证据引用分组、确认门合并、基线更新为新 commit、基线缺失回落全量
