# /mcp add 引号值添加期拒收（快通道追认登记）

## 问题陈述

用户在 dsh 对话以 `/mcp add remote … --header=Authorization="Bearer …"` 接 server：斜杠命令按空白切 token、不做引号剥离，添加「成功」但头值残缺（`"Bearer`），失败延迟到连接期才暴露（need 20261119-5625 背景节会话实测）。

## 方案

parseAddOptions 选项值含引号（`"`/`'`）即拒收：error 信息点名引号、给出 `mcp_manage`/面板替代入口与 `${credential:REF}` 建议；usage 帮助文本同步。

## 用户故事

- 作为 dsh 使用者，我想让带引号的错值在添加期被拒并告诉我替代入口，以便不产生静默坏数据。

## 实现决策

- 拒收守卫置于 add 选项解析的值分支（cwd/env/header 全覆盖）；裸 `--` 后的位置参数为文档声明的原始通道，不守卫。
- 拒收信息三要素：点名引号、替代入口（`mcp_manage` 工具 / 右栏面板）、敏感值模板建议。

## 测试决策

- 单测 red-green：引号头值 → error 拒收 + settings 零调用（test/unit/dsh-mcp-plugin.test.ts）。

## 验收场景

- [FR-1 | 工单级] Given 选项值含引号，When add，Then error 拒收（信息含「引号」与替代入口）且 settings 零调用。
- [FR-2 | 工单级] Given usage 文本，When 检视，Then 含「引号拒收」与复杂值入口表述。

## 非目标

- 引号感知解析（斜杠命令直接支持带空格/引号值）——round-3 候选。
