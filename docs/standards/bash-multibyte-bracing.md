# bash 3.2 变量展开紧邻多字节字符必须加花括号

本仓库门禁与演练脚本以 bash 3.2 为兼容底线（`check.sh` 头注"依赖：bash 3.2+"），且字符串高频混排中文。bash 3.2 扫描 `$VAR` 的变量名按单字节判定名字字符：`$VAR` 紧邻多字节字符（全角括号、】、：等）时，其 UTF-8 字节被并入变量名，展开成未定义变量——`set -u` 下直接 `unbound variable` 中止（2026-11-07 spec 0012 验收演练两处实证：`$GATES】`、`$rc（` 均触发，脚本在门处中止）。

规则：

1. `$VAR` 后一字符是非 ASCII → 必写 `${VAR}`；后随 ASCII（空格、半角标点、`/`）可省。
2. 拿不准一律加花括号——花括号在任何 bash 版本都安全。
3. 脚本日志禁用 `head -c N` 截断含中文的提交主题——切出半个多字节字符会让后续 awk/sed 报 `multibyte conversion failure`（同日实证）；截断展示用 `%h` 等 ASCII 格式字段。
