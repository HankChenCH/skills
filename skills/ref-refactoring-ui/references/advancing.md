# 持续进阶：精进设计眼力

> ← 原书 09「持续进阶」

九章章法之外，能力靠持续研究好设计来积累。本章只剩两条可执行的习惯。

## 规则

1. **留意那些你不会做出的决定**。遇到喜欢的设计就问：「这位设计师做了什么我根本想不到的事？」——反转背景色的日期选择器、放进输入框里的按钮、双色大标题——收集这些反直觉决定为新点子。（原书 09「留意那些你不会做出的决定」）
2. **不偷看开发者工具，重建你最喜欢的界面**。重做一遍再与原版对比，差异会逼你自己摸出「给标题减行高」「给全大写加字距」「叠多层阴影」这类技巧。（原书 09「重建你最喜欢的界面」）

## 自查口令

最近一次拆解别人的设计细节是什么时候？我是在积累点子库，还是在重复同一套手法？
