# 层次感：用光与阴影表达远近

> ← 原书 06「营造层次感」

界面元素有浮起与凹进之分，靠的是模仿现实光源与有目的地使用阴影。本章给
出模拟光的规律、高度体系与两层阴影的搭法。

## 规则

1. **记住光源规律：光从上方来**。凸起元素上沿更亮（上边框或小垂直偏移内阴影）、下方加深色小阴影；内凹元素相反——下沿亮，顶部加深色内阴影。亮边手动挑色，别用半透明白直接叠（会吸走底下饱和度）。（原书 06「模拟光源」）
2. **用阴影大小表达高度，别当装饰**。小阴影=略高于背景（按钮），中等阴影=悬浮更高（下拉菜单），大阴影=最靠近用户（弹窗）；离用户越近越抓注意力。
   - 正例：按下按钮时换成更小阴影或去掉——像被按进页面。
   - 反例：全站一种阴影，z 轴信息为零。（原书 06「用阴影传达高度」「把阴影和交互结合起来」）
3. **建立五档左右的高度体系**。先定最小与最大阴影，中间大致线性补齐；阴影种类不必多，与颜色字号一样按体系取用。（原书 06「建立一套高度体系」）
4. **一层阴影不够时分两层**：外层大而柔和、垂直偏移明显，模拟直射光投影；内层小而紧、偏移更小，模拟环境光照不到的贴地阴影。高度越高的档，内层阴影越轻。（原书 06「阴影可以分成两层」）
5. **扁平设计照样有层次**：同色系下浅色浮起、深色凹进；或用不模糊、只在垂直方向偏移的短实心阴影。（原书 06「扁平设计也能有层次感」）
6. **让元素重叠制造层次**：卡片横跨两种背景交界、控件高过父容器；重叠的图片之间加一圈与背景同色的「隐形边框」留缝，避免互相干扰。（原书 06「让元素重叠出层次」）
7. **模拟光别玩过头**。借视觉线索制造层次即可，追求照片级真实往往产出又乱又不清楚的界面。（原书 06「别玩过头」）
