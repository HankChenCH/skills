# 图片运用：稳定对比度与正确缩放

> ← 原书 07「图片的运用」

图片的成败常在缩放与文字可读性两处。本章给出照片来源纪律、文字压图的
对比度手段、图标与截图的缩放红线、以及用户上传图的防御处理。

## 规则

1. **照片要么专业拍摄，要么用好图库**。需要特定照片请专业摄影师；通用需求用图库（含免费高质量来源）。别用占位图设计然后指望回头随手替换。（原书 07「用好照片」）
2. **文字压图前先压平图片的动态范围**。照片明暗跨度大，文字对比度就忽有忽无；按需选择：半透明蒙版（黑压亮部护浅字、白提暗部护深字）、降低图片对比度（同时调亮度补偿）、给图着色（降对比→降饱和→叠纯色 multiply 填充）、或大模糊半径零偏移的文字光晕。
   - 正例：主视觉图叠深色渐变蒙版后白标题全程可读。
   - 反例：亮部吃掉白字、暗部吃掉黑字，反复换颜色都救不回。（原书 07「文字需要稳定的对比度」及小节）
3. **别放大小尺寸画的图标**。16–24px 画的矢量图标放到三四倍依旧细节不足显笨重；需要大图标就按大尺寸画，或把小图标装进带背景色的形状里占位。（原书 07「别放大图标」）
4. **别缩小细节截图**。全尺寸截图缩 70% 后文字变成不可辨认的糊点；改用更小屏尺寸截取、只截局部、或画去掉细节的简化线稿。反向同理：favicon 按目标尺寸重画极简版，别让浏览器替你缩。（原书 07「别缩小截图」「图标也别缩小」）
5. **用户上传的图要防御性展示**。固定尺寸容器居中裁切（如 background-size: cover）防止破坏布局；图片背景与界面背景相近渗色时，加轻微内阴影或半透明内边框，别用会与图内颜色打架的硬边框。（原书 07「当心用户上传的内容」）
