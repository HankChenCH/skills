# 文字设计：字号阶梯与排版纪律

> ← 原书 04「文字设计」

文字是界面的主体。本章解决四件事：字号阶梯怎么定、字体怎么选、行长行高
怎么配、对齐与字距什么时候该动。

## 规则

1. **建立手工定制的字号阶梯，用 px 或 rem，不用 em**。不必追求模数比例的数学纯粹——它会带来小数尺寸与过死的跨度；手动挑一组限制够用又不缺档的值。
   - 正例：12/14/16/20/24/32px 一类的手工阶梯，与间距阶梯配合。
   - 反例：基于 em 的嵌套字号算出 17.5px 这种阶梯外的值。（原书 04「建立一套字号阶梯」「别用 em 单位」）
2. **字体保守起步，用硬条件筛**。界面默认中性无衬线或系统字体栈；优先选样式（字重+斜体）多于五种、正文 x 高度大不压缩的字体；流行字体大概率是好字体。（原书 04「用好字体」）
3. **行长控制在每行 45–75 字符（约 20–35em）**。内容区因图片或大组件需要更宽时，段落本身仍保持这个宽度——同一内容区用不同宽度反而更精致。
   - 正例：文章正文限宽，配图溢出到更宽的容器。
   - 反例：文字迁就布局被拉到 100+ 字符一行，读者串行。（原书 04「控制好行长」）
4. **混用字号时按基线对齐，不要垂直居中**。眼睛天然感知基线这条参照线；居中会让挨得近的不同字号显得别扭。（原书 04「对齐基线，而不是居中」）
5. **行高与字号成反比、与行长成正比**。窄内容 1.5 够用，宽内容可到 2；大标题行高可以低到 1，小字号才需要额外行距帮眼睛找下一行。（原书 04「行高讲究比例」）
6. **对齐以可读性为准**。长文本左对齐，超过两三行不要居中（宁可改短文案）；表格数字右对齐便于比较；两端对齐必须同时开断词。（原书 04「对齐要以可读性为准」）
7. **字距默认别动，两种情况例外**：大标题用字距宽的字体时收紧字距；全大写文字加大字距弥补字母特征变少的可读性损失。反向操作（标题字体加字距用于小字）行不通。（原书 04「有效使用字距」）
