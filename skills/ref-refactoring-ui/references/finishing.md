# 收尾打磨：亮点、空状态与去边框

> ← 原书 08「收尾打磨」

层级、间距、字体都对，设计仍可能平淡。本章给低成本加亮点的手法、空状态
纪律，以及「少用边框」的区隔替代方案。

## 规则

1. **把默认样式做到极致，而不是加新元素**。项目符号换成对勾/箭头等图标；引号放大换色提拔成视觉元素；自定义复选框与单选按钮，选中态直接用品牌色——最省事的「有设计感」。（原书 08「把默认样式做到极致」）
2. **用强调色边框加视觉亮点**。沿卡片顶部、当前导航项、提示消息侧边、大标题下短条或整个布局顶边加一条彩色边框，即可显著提升「被设计过」的观感。（原书 08「用强调色边框加点颜色」）
3. **装饰背景而非堆内容**。换面板背景色或低对比渐变（两色相差不超过 30°）、加对比度压低的重复图案或简单几何形状——始终不干扰前景内容。（原书 08「装饰你的背景」）
4. **空状态是第一次接触，是优先事项**。放图片或插画吸引注意、突出行动号召、藏起点了也没用的标签页与筛选器；别拿一张空表应付。（原书 08「别忽视空状态」）
5. **少用边框，区隔另有三招**。优先用阴影（更轻的轮廓）、相邻元素两种稍异的背景色、或直接拉开间距；已用背景色区分时试着去掉边框，多数时候并不需要。
   - 正例：两张并排卡片用阴影区分边界。
   - 反例：到处 1px 边框，界面杂乱拥挤。（原书 08「少用边框」）
6. **跳出组件的固有成见**。下拉菜单可以多列多区块，表格可合并无排序需求的列、可放图片，单选按钮可换成可选择卡片——约束有力量，但别让成见限制设计。（原书 08「跳出框框去想」）
