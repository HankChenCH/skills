# 视觉层级：让重点一眼可见

> ← 原书 02「层级就是一切」

视觉层级指界面里各元素相比之下显得有多重要。所有元素都在抢注意力时界面就
是嘈杂的糊墙；刻意弱化次要信息、突出重点，界面立刻顺眼——哪怕配色字体布局都不变。

## 规则

1. **别把层级全交给字号，用字重和颜色分担**。主要元素加粗而非放大；辅助文字用更柔和的颜色而非更小的字号。
   - 正例：标题同字号下加粗到 600/700 传达重要性。
   - 反例：主内容字号过大、辅助文字小到难读——重活全压给了字号。（原书 02「大小不是一切」）
2. **文字颜色只留三档、字重只留两档**。深色给主要内容、灰色给次要内容、更浅的灰给第三级内容；常规字重（400/500）为主，加重字重（600/700）做强调；避开 400 以下字重——小字号下太难读。（原书 02「大小不是一切」）
3. **彩色背景上不要用灰色文字，改用同色相手动挑色**。把文字颜色调得更接近背景色来降对比度，别直接降白色文字的不透明度——那会让文字发闷、像被禁用。
   - 正例：绿色横幅上的次要文字选同色相、调低饱和度与明度的新色。
   - 反例：绿底上放浅灰文字，或白色文字加半透明，看起来发白失神。（原书 02「不要在彩色背景上用灰色文字」）
4. **用弱化来强调**。主元素怎么都突出不了时，去弱化与它抢注意力的元素——未激活导航项给更柔和的颜色，抢戏的侧边栏干脆不给背景色。（原书 02「用弱化来强调」）
5. **标签是万不得已的选择**。先试靠格式与上下文（邮箱格式、部门名位置）省掉标签；再试合并（「Bedrooms: 3」改写「3 bedrooms」）；必须用标签时把它当次要内容弱化，除非用户是来扫标签找数据的（如技术规格页）。（原书 02「标签是万不得已的选择」）
6. **视觉层级与文档层级分开**。h1/h2 这类语义标签照语义选，视觉大小按层级自由定——应用界面里的区块标题多是标签而非标题，通常应当相当小。（原书 02「把视觉层级和文档层级分开」）
7. **操作按钮按层级设计，不按语义平铺**。主要操作实心高对比一眼可见；次要操作描边或低对比背景；第三级操作做成链接。破坏性操作若非页面主要操作，按次级样式处理，把又大又红留给确认步骤。（原书 02「语义是次要的」「破坏性操作」）
8. **用对比度补偿字重，用字重补偿对比度**。图标偏重就降它的颜色对比度配平；细边框加深显得生硬时，改为略加粗保持柔和的同时更醒目。（原书 02「平衡字重与对比度」）
