# 色彩：色阶体系与对比度

> ← 原书 05「色彩的运用」

配色不是挑五个「完美」色值，而是建一套够用的色阶体系。本章解决：用什么
语言思考颜色、调色板怎么搭、对比度与无障碍怎么兼得。

## 规则

1. **用 HSL 思考颜色**：色相（色轮位置）、饱和度（多鲜艳）、明度（多接近黑/白）是眼睛能直觉操作的属性；网页设计用 HSL 而非设计软件常见的 HSB——浏览器只认 HSL，两者明度/亮度并不同义。（原书 05「把 hex 换成 HSL」）
2. **提前定好色阶体系，禁止临时算色**。灰色系备 8–10 阶，主色与强调色各备 5–10 阶；搭建流程：先选基色（适合当按钮背景）→ 定两端（最深给文字、最浅给带色背景）→ 补中间空档。不要用 lighten/darken 函数现算——那正是你拥有 35 个几乎一样的蓝色的原因。
   - 正例：九档色阶编号 100–900，直接取用。
   - 反例：写页面时随手微调出新色值，色板越来越乱。（原书 05「你需要的颜色比你以为的多」「提前把色阶定好」）
3. **明度偏离 50% 时提高饱和度，别让色阶发灰发白**；必要时小幅旋转色相改亮度——变亮朝黄/青/品红转，变暗朝红/绿/蓝转，幅度不超过 20–30°。（原书 05「别让明度毁掉你的饱和度」「通过旋转色相来改变亮度」）
4. **灰色不一定是灰的**。给灰色系加一点蓝显冷、加一点黄或橙显暖，让界面有温度倾向；更浅与更深的色阶同步提高饱和度，避免两端发白。（原书 05「灰色不一定是灰的」）
5. **无障碍对比度可以优雅达成**（正文 4.5:1、大字 3:1）：彩色背景上的文字若深背景白文字太抢戏，就把对比关系反过来用浅背景深文字；彩色背景配彩色文字时，把文字色相朝更亮的色相（青/品红/黄）旋转。（原书 05「无障碍不等于难看」）
6. **不要只靠颜色传达信息**。正向/负向辅以图标或形状；图表区分数据系列靠明暗对比，别靠色盲用户难分辨的不同色相——颜色永远只该支撑设计已在表达的东西。（原书 05「不要只靠颜色」）
