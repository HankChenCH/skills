# setup-migrate：存量项目套件迁移

你只做一件事：对**已使用 matt / superpower 等外来技能套件的存量仓库**做一次迁移——
识别安装痕迹、外来产物逐件翻译处置、接入本套件门禁、对账清单收口，
之后所有会话只按本套件规则工作。
其余一切（识别期改文件、擅自处置非点名套件痕迹）一律拒绝。
拒绝不是失礼，是本技能的职责。

**按需加载**：进入识别阶段前才 Read references/identify-protocol.md，
进入翻译阶段前才 Read references/translation-mapping.md，
进入处置阶段前才 Read references/disposal-protocol.md，
清单收口前才 Read references/ledger-template.md，一次只载一个。

## 0. 前置：入口门禁

- `git rev-parse --show-toplevel` 必须成功；失败 → 停止："这里不是 git 仓库，
  套件迁移只对 git 仓库运行。"
- 校验技能自身文件完整（SKILL.md、references/identify-protocol.md、
  references/translation-mapping.md、references/disposal-protocol.md、
  references/ledger-template.md）；缺失 → 停止报告安装损坏。
- **不要求已接入本套件**（`.sdlc/check.sh` 存在与否不构成入口前置）：
  未接入仓库照常进入识别，接入与否只在落盘阶段分路（§3 接入步）。

## 1. 判定接入状态（只读判定，不写任何文件）

- `.sdlc/check.sh` 存在 → 已接入：落盘阶段仅补迁移产物与对账清单，
  接入资产逐字不变。
- 不存在 → 未接入：落盘阶段先按 setup-workspace 全流程完成接入（含其决策点），
  随后落迁移产物，一次会话完成；识别照常先行。

## 2. 识别（全程只读）

Read references/identify-protocol.md，按其特征清单识别两套点名套件——
**matt** 与 **superpower**——的安装痕迹（技能文件、规则文件、产物落点），
产出迁移报告交用户过目，确认后才进入翻译处置（§3）。

- 识别全程**只读**：不改、不建、不删目标仓库任何文件（含临时文件）。
- 只认两套点名套件的特征清单，不做通用识别器；查无痕迹的类别显式写「未发现」。
- 识别出**非点名套件**的痕迹 → 对账清单标「未处理」并提示用户，
  不擅自处置（E1）。

## 3. 流程骨架：翻译 → 处置 → 接入 → 清单收口

识别确认后按五步推进；识别已在 §2 落地，翻译 / 处置 / 接入 / 清单收口四步的
操作协议由后续工票落地，本票只立骨架，不超前实现（契约原文见蓝图 §11.19）：

1. **翻译**：Read references/translation-mapping.md，外来产物逐件翻译映射成本套件
   形态（分态规则：未完成的外来工作进正向流程现态，已完成的历史产物落沉淀形态），
   逐件翻译，不以原样归档替代。
2. **处置**：Read references/disposal-protocol.md，tracker 开着的-issue 关闭并注明
   已迁移；生命周期类外来技能移除或归档（写作类保留；处置用户全局安装前必须经
   用户确认作用域，不擅动）。
3. **接入**：未接入仓库先 setup-workspace 全流程接入再落迁移产物，一次会话完成；
   已接入仓库仅补迁移产物，接入资产逐字不变。
4. **清单收口**：对账清单落 `docs/migrations/NNNN-slug.md`（Read
   references/ledger-template.md 取模板），每件外来产物一行：
   来源（本地路径 / issue 编号 + 平台）→ 归宿（新产物路径 / 归档位置 /
   显式弃置及理由）→ 处置结果（已翻译 / 已关闭 / 失败待补 / 未处理）。
   对账清单是轻产物，不进 check.sh 门禁；frontmatter 仅 `id` / `created`，
   一次迁移一张，落盘即终态。

## 4. 出口（报告 + 对账清单 + 指路，不自动串联）

报告迁移结果与对账清单位置；出口指路 setup-reconstruct 可选串联知识逆向——
迁移只保证外来产物归宿，存量代码的知识逆向是另一件事，用户自选触发。
按需服务定位：sdlc next-mode 路由表不加行，没有任何技能自动调用本技能，
迁移一律用户手动触发。

## 5. 中断与交接

识别全程只读，中断即无损；翻译处置进展记进对账清单对应行
（失败待补 / 未处理），状态在盘上不在对话里。
重入：重跑 §0–§2 判定，向用户确认从哪一步继续，不凭记忆续写。

## 禁止事项（任何时候）

- 识别阶段改动目标仓库任何文件。
- 擅自处置非点名套件痕迹——一律标「未处理」交用户。
- 以原样归档替代翻译。
- 处置用户全局安装的技能前不经用户确认作用域。
- 进 sdlc next-mode 路由表，或替正向流程技能做串联。
