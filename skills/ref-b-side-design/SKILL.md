# ref-b-side-design：什么是好的 B 端体验设计

总标准只有一条：**复杂守恒——产品的复杂性不可移除，只能决定谁来处理它；设计以客户视角重构复杂性的归属，把复杂留给设计侧、把简单留给客户，落到体感就是"找得到 + 看得懂"。**
以下总纲是四册的公共标准，章法细则按路由表加载，不整载。

## 任务路由（你现在要做什么，就载哪册；一次只载一个）

| 信号（你现在要做什么） | 分册 |

| 功能归类（MECE）、落地信息架构与导航结构、给新增功能归位、画泳道图排效率优先级 | references/architect-structure.md |
| 设计关键界面：错误防线、响应反馈节奏、聚焦核心竞争力打造体验亮点 | references/craft-key-interface.md（由工票 20261107-3155 交付） |
