# 桌面端对象：布局模式与视觉决策要点

design-ui 对象路由选中本分册后加载。适用：桌面应用（原生或跨平台）——窗口、
菜单、文件系统交互。核心动作：大屏、长会话、精确指针三个条件翻成面板布局
与键盘流决策。

## 布局模式（按约束三要素选型，决策注明满足哪条约束）

- **多面板主工作区布局**：主工作区承载核心任务，辅助面板（导航/属性/日志）
  可停靠、可隐藏——对齐"面板主次"约束；默认开合状态写明，不写死坐标。
- **并排对照布局**：跨单据/多版本并排可见——对齐"对照核阅"约束；
  分栏比例与联动滚动按任务定。
- **键盘流布局**：高频动作有快捷键，焦点顺序可视、命令面板可达——
  对齐"键盘几步内完成"约束；危险动作拦截在路径上（确认或可撤销）。
- **长会话状态布局**：中断恢复回到原状态、批量操作有进度可中止——
  布局给进度与恢复入口留常驻位置。

## 视觉决策落法（桌面口径）

- 密度：桌面允许比 Web 更密——行高与留白取阶梯下限，但正文可读口径不降。
- 焦点态：键盘焦点必须可见（描边或底色变化），焦点色对背景对比度 ≥4.5:1。
- 触控豁免：桌面指针设备不受 44px 触控约束，但点击目标仍不小于可点的
  合理下限（约 24px），密集工具栏靠悬浮提示补偿。
- 阶梯：间距与字号对齐基线分册；无基线用套件默认阶梯。

## 好 / 坏对照

- 好："批量导入进度面板常驻底部、可中止；Esc 取消后保留已完成行并可续传
  ——对齐'批量可回退'约束。"
- 坏："左侧导航树、右侧编辑器。"——照抄惯例却说不出满足哪条约束，
  先指回约束再定面板。

## 自查口令

面板主次与默认开合对齐约束了吗？键盘焦点可见且对比度够吗？
批量与中断恢复的入口在布局里有常驻位置吗？
